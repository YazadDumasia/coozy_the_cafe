# Coozy the Cafe

<!-- ![Coozy the Cafe Logo](assets/images/logo.png) -->

A modern and feature-rich Flutter application for a cafe experience.

## Description

Coozy the Cafe is a comprehensive mobile application designed to provide a seamless and enjoyable experience for both customers and staff. It offers a wide range of features, from browsing the menu and placing orders to managing inventory and user accounts.

## Features

*   **Beautiful UI:** A visually appealing and user-friendly interface built with Flutter.
*   **State Management:** Utilizes `flutter_bloc` for robust and predictable state management.
*   **Navigation:** Uses `go_router` for a flexible and powerful routing solution.
*   **Localization:** Supports multiple languages with `flutter_localization`.
*   **Rich Media:** Caching network images, image cropping, and Lottie animations for a dynamic user experience.
*   **Maps and Location:** Integrates with Google Maps for location-based services.
*   **Local Storage:** Uses `Drift` for on-device data persistence.
*   **And much more!**

## Getting Started

### Prerequisites

*   Flutter SDK: Make sure you have the latest version of the Flutter SDK installed. You can find instructions on the [official Flutter website](https://flutter.dev/docs/get-started/install).
*   An editor like Visual Studio Code or Android Studio.

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/coozy_the_cafe.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd coozy_the_cafe
    ```
3.  Install the dependencies:
    ```bash
    flutter pub get
    ```
